# Monnaie locale : l'autre modele

## Pourquoi cet ecran existe

Une chaine de blocs sert a se passer d'un tiers de confiance. C'est sa seule
raison d'etre, et c'est ce qui justifie son cout.

Dans une monnaie locale, la collectivite **est** ce tiers de confiance, et
personne ne souhaite s'en passer. Une chaine y apporterait donc un cout
considerable pour resoudre un probleme inexistant, tout en imposant ses
contraintes - a commencer par la plus rude : une phrase de recuperation
perdue, et les fonds le sont aussi.

L'ecran n'est pas un discours : c'est un registre qui fonctionne. Comptes,
emissions, paiements, annulations. Deux cents lignes la ou la chaine en
demande dix fois plus, et utilisable sans rien comprendre a la cryptographie.

## Ce que la comparaison montre

|                      | Chaine de blocs            | Registre local        |
|----------------------|----------------------------|-----------------------|
| Qui garantit         | Le calcul d'inconnus       | La collectivite       |
| Perdre son acces     | Fonds perdus               | Mot de passe reinitialise |
| Erreur de paiement   | Definitive                 | Annulable             |
| Delai                | Minutes a heures           | Immediat              |
| Cout par paiement    | Frais de reseau            | Aucun                 |
| Energie              | Considerable               | Celle d'un site web   |
| Pour l'utiliser      | Comprendre les cles privees| Scanner un QR code    |

Aucune colonne n'est meilleure. Bitcoin existe pour envoyer de l'argent a un
inconnu sans permission ; une monnaie locale, pour que la valeur reste sur un
territoire.

## Le bouton d'annulation

C'est le detail qui resume tout. Sur le registre, une erreur se corrige en un
geste - et le code refuse l'annulation si la somme a deja circule, ce qui est
verifie par les tests. Sur une chaine de blocs, aucune correction n'est
possible, jamais.

Cette irreversibilite est une qualite quand on se protege d'un Etat ou d'une
banque. C'en est une catastrophique quand la boulangere s'est trompee d'un
zero.

## En pratique

Plus de quatre-vingts monnaies locales circulent en France, encadrees par la
loi de 2014 sur l'economie sociale et solidaire. Beaucoup ont une version
numerique, et des communes y participent.

Avant d'en construire une, il vaut mieux regarder celles qui tournent depuis
dix ans : elles ont deja rencontre les problemes qu'on n'a pas encore
imagines.
